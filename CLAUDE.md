## Project Overview

ERGMEgo.jl is a Julia port of the R `ergm.ego` package (StatNet collection) for fitting Exponential Random Graph Models (ERGMs) to egocentrically sampled network data. It enables inference about population-level network properties from ego samples where each sampled "ego" reports their local network (alters and alter-alter ties).

## Architecture

The entire package lives in a single module file: `src/ERGMEgo.jl`. It is organized into these sections (in order):

1. **Data Structures** — `EgoNetwork{T}` (single ego observation with alters, alter ties, attributes; the inner constructor refuses a non-square or asymmetric `alter_ties`, a duplicated alter — `allunique(alters)`, the wide-to-long survey mistake that doubled the ego's degree — and a `true` on the diagonal, each naming the ego and the alter) and `EgoData{T}` (collection of ego networks with population size, sampling weights, survey design info; `_check_sampling_weights` in the inner constructor refuses a NaN/Inf/negative weight naming the ego index, id and value, and an all-zero vector — so `ego_design`, `as_egodata(…; weight_col)` and every downstream statistic never see one; a single zero weight is legal). Helper functions: `n_alters`, `alter_degree`, `ego_degree`, `n_alter_ties`, `summary_stats` (design-weighted mean AND median degree; `_weighted_median` is the 0.5 quantile of the weight-estimated distribution with the midpoint convention, deliberately not StatsBase's interpolating `median(x, Weights)`). One-line `show` methods for `EgoNetwork`, `EgoData` and `EgoERGMModel` in ERGM.jl's `ERGMModel` style (`_plural` helper).
2. **Data Preparation** — `as_egodata(ego_df, alter_df; aatie_df=...)`: ergm.ego-style frames (egos, ego-alter rows, alter-alter ties; **without `aatie_df` the data records `design[:alter_ties_observed] = false`** — uncollected ties are unobserved, not absent — and every statistic with `_needs_alter_ties(term) == true` (`EgoTriangle`, the GOF's `_EgoESP` and `_EgoMeanAlterTies`) refuses it through `_require_alter_ties` in `compute`; `summary_stats(ed).mean_alter_ties` is then `NaN`); alter IDs are preserved (never relabeled) so cross-ego overlap works; every column a keyword names is checked up front by `_require_column` (ArgumentError naming column, keyword, frame and the frame's columns); a duplicated `(ego, alter)` row and an `aatie_df` self-tie row `(ego, a, a)` are refused in the frames' own terms before the `EgoNetwork` constructor would. `ego_design(ed; popsize, weights)` attaches the POPULATION size and/or weights (the development spelling `ppopsize=` is removed — a `MethodError`; the pseudo-population size is a keyword of `fit_ergm_ego` only). The `EgoNetwork` constructor also refuses an ego listed as its own alter and an `alter_attrs` vector whose length is not the number of alters.
3. **Ego-Specific Terms** — subtype `EgoTerm <: AbstractERGMTerm` (`import NetworkCore: name, compute` — the shared statistic protocol, `ERGMEgo.name === NetworkCore.name`, both re-exported so `compute(EgoEdges(), ed)` works with `using ERGMEgo` alone; `import ERGM: summary_stats`). `compute(term, ed)` returns the design-weighted per-capita statistic; `ego_contribution(term, ego)` is the per-ego value — `ergm.ego`'s `EgoStat.*` value (allocation-free for the count terms — `EgoNodeMatch`/`EgoNodeFactor` through the `_count_matches` function barrier over the abstractly typed `Dict{Symbol,Vector}` column, with a `::Int` assertion on the result so the division is static; `EgoNodeCov`/`EgoAbsDiff` call their kernels `_nodecov_sum`/`_absdiff_sum` through `_numeric_call`, which branches on the Int/Float64 column layouts so the call is static — 0 B, pinned; any other layout is a dynamic call that boxes the result); `ergm_term(term)` maps to the ERGM.jl term whose sufficient statistic it estimates (EgoEdges→Edges, EgoNodeMatch→NodeMatch, EgoNodeFactor(a; level=l)→NodeFactor(a; level=l), EgoNodeCov→NodeCov, EgoAbsDiff(a; pow)→AbsDiff(a; pow), EgoDegree(d)→Degree(d), EgoTriangle→Triangle with /3 for triple counting, EgoGWDegree→GWDegree, labelled `gwdeg.fixed.<decay>`; `decay >= 0`; EgoGWESP→GWESP, labelled `gwesp.fixed.<decay>`, per ego `Σ_alters w(s_a)/2` with `s_a` the alter's degree among the alter–alter ties (= the tie's shared partners), computed from `alter_ties` column counts without allocating — a clean-room implementation (the package is MIT, ergm.ego GPL-3): derived from Hunter 2007's published GWESP definition, with no ergm.ego or ergm code consulted, and validated against ergm.ego's outputs as a black box (`ego_terms.toml`) and against ERGM.jl's `GWESP` by brute force; keep any change to it clean-room; it needs collected alter ties and is triadic like `EgoTriangle`; there is no shared-partner cutoff, whereas ergm.ego's `gwesp` leaves out ties with more than `cutoff = 30` shared partners — ergm's own `gwesp` and ERGM.jl's `GWESP` count them; `EgoGWESP(α; fixed=false)` — the curved gwesp — is refused, because ERGM.jl's curved MCMLE fits a whole network, not target statistics), EgoESP(k)→ESP(k) (ERGM.jl's term, added for it; per ego `#{alters with alter-tie degree k}/2`, allocation-free column counts like `EgoGWESP`; needs alter ties, triadic — ergm.ego's offset formula for `esp` carries `transitiveties = -1/3`, recorded in the fixture; it is also the GOF's "edgewise shared partners" statistic, which replaced a private allocating `_EgoESP`), EgoConcurrent→Concurrent (`1[deg ≥ 2]`, not halved; `by=` refused), EgoMM(attr)→NodeMix cells (ergm.ego's `mm(attr)` default form: per cell `(l1, l2)` the alters whose unordered pair with the ego is `{l1, l2}`, halved; `EgoMM(attr)` is a specification expanded by `_expand_ego_term` through `_mm_cells`/`_mm_levels` — levels are the sorted values at EITHER END OF A REPORTED TIE (an alter-only level is in, an isolated ego's level is out; R's output pinned three ways in `ego_mixing_esp.toml`), cells `l1 ≤ l2` column-major as R/NodeMix order them, first cell dropped; `EgoMM(attr, l1, l2)` one cell; labels `mm[<attr>=<l1>,<attr>=<l2>]` while `name(ergm_term(t))` is NodeMix's `mix.<attr>.<l1>.<l2>`; `EgoMM(:A, :B)` (R's `mm(A~B)`), `levels=`, `levels2≠-1` refused; `_refuse_absent_levels` refuses a fit whose mm cell has a positive target but a level no ego with pseudo-population copies carries — no simulated network can match it; ergm.ego 1.1.4's `mm` errors on weighted data, ERGMEgo's weights as every term). The three new terms are implemented from their documented definitions (ergm's `esp`/`mm`/`concurrent` help pages) — no ergm/ergm.ego code consulted — and validated against ergm.ego's outputs as a black box; keep them clean-room. **Labels are `ergm.ego`'s**: `name(t)` of a built-in term is R's label (`edges`, `nodematch.<a>`, `nodefactor.<a>.<l>`, `nodecov.<a>`, `absdiff[pow].<a>`, `degree<d>`, `triangle`, `gwdeg.fixed.<α>`, `gwesp.fixed.<α>` — `name(ergm_term(t))` wherever that exists), and so are `coefnames(fit)` and the rows of `coeftable(fit)`; pinned against `ego_terms.toml` (`term_names` and every fit block's `*_names`). The GOF-internal terms are `degree<d>+`, `esp<k>`, `mean degree`, `mean alter ties`. Per-ego values: nodefactor `(1[x_ego = l]·deg + #alters with l)/2`, nodecov `(x_ego·deg + Σx_alter)/2`, absdiff `Σ|x_ego − x_alter|^pow/2`, degree `1[deg = d]` (not halved: a vertex property). A multi-level `EgoNodeFactor(attr; levels, base=1)` (R's `levels=-1`: the sorted values OF THE EGOS, first dropped) is a specification: `_expand_ego_terms(terms, ed)` turns it into one single-level term per level; `fit_ergm_ego` expands ONCE before `_fit_ergm_ego` (so bootstrap refits keep the data's levels), `ego_target_stats` expands, `compute` of the unexpanded term is the sum of its levels (ERGM.jl's NodeFactor convention), and its `ego_contribution`/`ergm_term` throw. Attribute terms need the attribute on the ego and its alters (`_require_attribute`); R's ego-only fallback is not ported. `EgoDegree(d)` refuses `d < 0`; R's `degree(0:3)` is `EgoDegree.(0:3)`. `ego_mixing_matrix` is a descriptive function returning (levels, matrix). An ego lacking the attribute of an `EgoNodeMatch` or of `ego_mixing_matrix` is an `ArgumentError` from `_missing_attribute_error` (attribute, ego, which side lacks it), and a carried attribute holding `missing` (ego value or any alter's) is one from `_missing_value_error` via `_check_attribute_values` (attribute, ego, how many alters; `_n_missing` is a function barrier that folds to nothing on a `Vector{String}` column, so the hot path stays allocation-free) — never a silent `0.0`/skip/TypeError; `fit_ergm_ego` therefore fails at the targets, before any MCMC or rng draw. `EgoTerm` is exported (as ERGM exports `AbstractERGMTerm`) with a docstring showing a custom subtype; `ergm_term` and `ego_contribution` are declared `public` (documented in the API reference "Terms" page with a fittable custom-term example) because they are the hooks a custom term extends (development versions spelled them `_ergm_term` and `_ego_contribution`). `ergm.ego`'s curved `gwesp`, `nodemix`, `absdiffcat`, `degrange`, `concurrentties`, `degree1.5`, `transitiveties`, `cyclicalties`, `meandeg`, `mm`'s two-attribute/margin/level-selection forms, `concurrent(by=)` and `degree(by=, homophily=)` have no ego counterpart, and there is no `simulate(fit)`; both are stated in README "Not implemented" and the terms guide.
4. **Model and Estimation** — `EgoERGMModel{T}` (fields `ego_terms`, `ergm_terms`, `data`, `ppopsize`, `popsize`, `targets`, `ppop_counts`), `EgoERGMResult{T}` (… `netsize_adjustment`, `converged`, `mcmc_convergence`, `sim_stats`, `termination`, `se_type`; ONE 12-field positional constructor), `fit_ergm_ego` (const alias `ergm_ego`; the development alias `fit_ego_ergm` and keywords `max_iter`/`tol` are removed, listed in the "Renamed and removed names" table of `docs/src/api/estimation.md`). `fit_ergm_ego` is a thin keyword wrapper: it expands the terms (`_expand_ego_terms`), packs the keywords into the concretely typed `_FitControls` struct and calls `_fit_ergm_ego(ed, terms::Vector{EgoTerm}, controls, rng)` — so the fit is compiled once, not once per `nothing`/`Int` keyword combination (first fit 2.1 s → 0.14 s with the precompile workload). The fit, in order:
   - **Network size as `ergm.ego`.** `N = something(popsize, ed.population_size, 1)`: an unknown population size is `popsize = 1`, R's default, which makes the coefficients **per capita**. `ppopsize` defaults through `_default_ppopsize(N, n_egos)` to ergm.ego's `ppopsize="auto"`: `n_egos` when the population size is unknown, `N` when `1 < N ≤ 1000`; above 1000 it is `10·n_egos` (R: `N`), disclosed by `_ppopsize_note` in `show` and `approximations`. ergm.ego's two warnings are reproduced: requested size < `n_egos`, and = `n_egos` under unequal weights (`var(w) > √eps`). Pinned by `tri_percap` (default size = R's 100) and `ego_terms.toml`'s `default_ppop` block (R's real default, 69 egos). `netsize_adjustment = log(N/m)` is R's `netsize.adj` coefficient `−log(m/N)` (exactly `0.0` when `N == m`); the simulated model's edges coefficient is `coef[edges] + netsize_adjustment`. When a term is triadic (`_is_triadic(::EgoTriangle) = true`) and `N ≠ m`, the offset statistic is `edges − transitiveties/3`: `ergm_terms` gains a trailing `Offset(GWESP(0.0), -netsize_adjustment/3)` (gwesp at decay 0 = R's `transitiveties` on an undirected network; pinned against R). All Newton/convergence/variance algebra runs on the first `p` (free) columns; `_pseudo_theta(result)` rebuilds the full simulated-model coefficient vector for `gof`.
   - **Pseudo-population as `ergm.ego`'s `ppop.wt = "round"`.** `_ppop_counts(weights, m) = round.(Int, m·w/Σw)`; the realised size `sum(counts)` can differ from the request (an `@info` says so; fewer than 5 is an `ArgumentError`) and is what `model.ppopsize`, the targets and the offset use. An ego's count depends on its own weight only, so the composition is invariant under permutation of the egos (the pre-0.2 largest-remainder rounding gave the extra copies to the first egos). `_ppop_ego_index(counts)` is R's `ego.ind`.
   - **Start.** `_annealed_model` seeds ties at the target density and runs `_san!` (simulated annealing toward the targets in the scaled distance `Σ(g−t)²/max(|t|,1)`, tie-list delete / random-dyad add proposals, temperature decaying to 0; every draw from `rng`) — R's `san` step of `ergm(target.stats=)`. The start is `ERGM.mple` on that network (the MPLE function itself, not `fit_ergm`, so ERGM's `method=:auto` default does not apply; under a `NullLogger`; used only if it converged and is finite; otherwise the edges-only logit start). The transitive-ties offset is part of that MPLE (ERGM.jl fits a finite `Offset` on a dyad-dependent statistic; an earlier heuristic start that worked around a divergence there is gone).
   - **Targets at a bound (R's drop).** `_target_boundary(ego_terms, targets, m)` compares each target with `attainable_range(t, network(m; directed=false))` — R's `minval`/`maxval` through ERGM.jl's extension-API generic `ERGM.Extension.attainable_range`, to which this package adds the one method `attainable_range(t::EgoTerm, net) = attainable_range(ergm_term(t), net)` (the range of the ERGM term the ego term estimates, on the pseudo-population; no range table of its own, pinned by a test). A target at an end (to 1e-12) is ergm's `ergm.checkextreme.model` on `target.stats`: warned by `_warn_target_drop` in ergm's words, the coefficient set to ∓Inf in θ (the sampler's `_sampler_theta` turns it into ±1e300, so the statistic stays at its bound), and moment matching runs on the other columns `est` only (`targets_est`, `draw` subsets the sampled columns, `q = length(est)`); `vcov`/`vcov_design`/`vcov_estimation` are embedded with zero rows/columns for the dropped terms (standard error 0), `coeftable` gives z = ∓Inf and p = 0, `dof` counts finite coefficients, `_boundary_caveat` is printed by `show` and listed by `approximations`, and `sim_stats`/`termination.step` hold the estimated statistics only. `drop=false` (a `_FitControls` field) refuses before any MCMC, and so does `se=:bootstrap`. An all-zero edges target is refused (nothing to estimate). Pinned by `ego_terms.toml` block (f) (R's `-Inf` for `degree0` on the census without isolates; the old code returned a finite, "converged" −5.6) and the testset "A target at a bound of its statistic is fixed at ∓Inf".
   - **Moment matching = ERGM.jl's MCMLE loop on the targets.** **The sampler is `ERGM.Extension.mcmle_sampler`** (`mcmle`'s own, built once per fit on the annealed model with `n_free = q`, `max_n_samples = n_max`): the defaults are R ergm 4's, which ergm.ego runs underneath — `proposal=:spdyad` and `effective_size=64` (ESS-adaptive: ONE chain started from the annealed network, burned in `burnin` toggles once, continued between iterations — `16 × interval` re-burn — its interval starting at `interval ÷ 8` and doubled until the summed Geyer ESS reaches the target; the stored sample is `min(n_max, max(256, 32q, 4·target))` draws, and the confidence rule's boost goes through `sampler.resize`, raising the TARGET, capped at `n_max/4`). `effective_size=nothing` is the fixed-size design (`n_samples` draws `interval` apart after a fresh `burnin` from the annealed network each iteration, boosted up to `n_max`); `effective_size=nothing, proposal=:tnt` is bit-for-bit the pre-0.2 sampler (the loop-path tests pin their seeds on it). **Why**: under the old fixed-size TNT design the help-page model (14 statistics, 205 vertices) never passed the equivalence test in 60 iterations (≈ 6 min): TNT at interval 2091 gives ≈ 0.05 effective draws per draw on its gwesp/nodematch statistics, so the 4·3000 cap is ≈ 530 effective draws, while 14 statistics at precision 0.1 / 99 % need several hundred AFTER the step's noise (0.1·n_eff must beat χ²₁₄(0.99) ≈ 29 even with a perfect step); raising the cap to 48 000 draws converged it in 9 iterations (47 s). At the defaults it converges in 5–15 s. Per iteration: `sampler.draw` at θ, Hummel step length γ (cloud covers the targets when the Mahalanobis distance is below `_chisq95(p)`), step `γ·Σ⁻¹(targets − ḡ)` capped at `max_step_norm`, then the stopping rule: `termination=:confidence` (default) is `ERGM.Extension.confidence_test` (R ergm's equivalence test, with R's sample-size boost up to `max_n_samples = 4·n_samples`); `:hotelling` is the pre-0.2 t-ratio + Hotelling rule (`ERGM.mcmc_convergence`). `ERGM.Extension.confidence_test` is `public` in ERGM.jl. **The sample that passes is the final sample**; when `maxiter` (60) runs out, a fresh sample at the returned θ decides. A singular sampled covariance steps back halfway toward the last regular θ (three attempts) instead of stopping. `mcmc_convergence` (t-ratios, Hotelling p, n_eff) is always `ERGM.mcmc_convergence` on `sim_stats`; `termination` is `(rule, p_value, precision, confidence, n_samples, step)`: `step` is the coefficient step the equivalence test was evaluated at — the full Newton step from a sample that passed in the loop (which also needs Hummel γ = 1), zeros for the fresh post-`maxiter` sample and under `:hotelling` — so the test helper `assert_one_sample` recomputes `converged` EXACTLY from `sim_stats` (`ERGM.Extension.confidence_test` at that step, p-value bit-equal); the three one-iteration paths are pinned on seeds 2 (in-loop pass), 11 (post-step pass ⇒ converged, no warning) and 3 (post-step fail).
   - **Standard errors** `V(θ̂) = I⁻¹Σ_design I⁻¹ + I⁻¹/n_eff` — `ergm.ego`'s design + MCMC-estimation decomposition (`vcov_design`, `vcov_estimation`), with NO standalone `I⁻¹` term. `Σ_design` treats egos as independent, which under-covers the model parameter (a tie between two sampled egos is reported twice: variance ×(1+f), f = n/N; coverage ≈ 91 % at f = 0.1, 80–85 % at a census). `_se_caveat(result)` is THE sentence `show` prints (word-wrapped by `_print_wrapped`) and `approximations` lists. `se=:superpopulation` (`NetworkCore.check_se`) multiplies `Σ_design` by `1 + n_egos/popsize`. **Default (`se=nothing`): `:superpopulation` when popsize is known (`N > 1`, `n ≤ N`), `:design` otherwise**; `fit.se_type` records it and `vcov_design` holds the (possibly inflated) component. Measured coverage, N = 200, edges/nodematch: census 0.80/0.83 → 0.94/0.95; 100 egos 0.86/0.85 → 0.92/0.92; 50 egos 0.91/0.87 → 0.93/0.91; 20 egos 0.85/0.78 → 0.87/0.78; 100 of 1000 at mean degree 70: 0.93/0.84 → 0.94/0.85 (the composition of the pseudo-population is estimated — a second-order effect; stratified 10/10 gives 0.94/0.93). Pinned by a simulation testset (census N = 40 and 50-of-200). **Every comparison with an R fixture requests `se=:design` explicitly.**
   - **`se=:bootstrap`** (`_ego_bootstrap`): a bootstrap over egos through the ONE shared loop `NetworkCore.bootstrap_cov`. `simulate(rng, B)` draws every resample (`n` ego indices with replacement) and one refit seed per replicate up front from `rng`; `refit` rebuilds `EgoData` from the drawn egos with THEIR sampling weights, hence the pseudo-population and targets, and calls `_fit_ergm_ego` with the caller's controls (`se=:design`) under a `NullLogger` — a pure function of its replicate, so the threaded refits are thread-count independent (pinned in a fresh process). A refit that fails (unconverged, non-finite, or an `ArgumentError` in setup) is a `NaN` row: excluded, warned once, counted in `_se_caveat`/`approximations`, each quoting the family's sentence `_BOOT_EXCLUSION_BIAS` ("The standard errors are conditional on a finite refit: …biased downward.", verbatim ERGM's; the test asserts equality with `ERGM._BOOT_EXCLUSION_BIAS`). The covariance is `_robust_cov` (replicate correlations, IQR/1.349 scales; with few egos an extreme-composition resample inflates the plain sd by ~35 %) plus `f·vcov_design` when popsize is known. Measured coverage (scratch simulations outside the repository): 20 of 200 egos 0.94–0.97/0.98 over two independent runs (superpopulation 0.85/0.80–0.84), 50 of 200 at mean degree 56 0.98/0.99 (0.89/0.84) — conservative. Not the default (cost: `n_boot` fits); `show` recommends it below 50 egos. The in-suite coverage testset is 10 of 40 egos, 30 replicates, `n_boot=24`.
   Non-convergence warns, sets `converged == false`, and is printed by `show` and listed by `approximations` from the same `_nonconvergence_caveat`. The MCMC budget is the one internal helper `_mcmc_controls(m; n_samples, burnin, interval)` (described in prose on the API reference "Estimation" page; not `public`): `n_samples = max(400, min(3000, 20m))`, burnin/interval from `ERGM.Extension.mcmc_defaults(n_dyads)`; under ESS-adaptive sampling `n_samples` only sets the cap `max_n_samples = 4·n_samples`, `interval` the starting interval (÷ 8). Keyword `effective_size` (≥ 8 or `nothing`, validated up front) is a `_FitControls` field, passed to bootstrap refits. Keywords follow the ecosystem vocabulary (`maxiter`, `n_samples`, `rng`, `proposal`, `se`). StatsAPI: `coef`, `coefnames` (R's labels, a fresh copy; pinned with `check_statsapi(...; required=(…, :coefnames), strict=true)`), `stderror`, `vcov`, `confint`, `coeftable`, `nobs` (egos), `dof`; deliberately no `loglikelihood`/`aic`/`bic` (`objective == :moment`). Models must include `EgoEdges()`.
5. **Population Size Estimation** — `estimate_popsize`: `:horvitz_thompson` (the weight sum) and `:capture_recapture`, Lincoln–Petersen on **nominated alters who are sampled egos**: the egos are the equal-probability capture, the `R` nominations the second, `M` nominations of sampled egos, `N̂ = 1 + (n−1)(R+2)/(M+2)` (Chapman's correction on ties). Unequal weights and `M = 0` are `ArgumentError`s. Mean 207 at n = 80 on faux.mesa.high (N = 205), pinned by simulation; the pre-0.2 estimator (alter overlap of two halves split by input order) averaged 153. An unknown `method` is an ArgumentError naming it and listing both valid ones.
6. **Simulation** — `simulate_ego_sample(net::Network, n_egos; ego_attrs, missing=:error, report=false, rng)` is the ecosystem's `Network → EgoData` conversion adapter: `require_observed(net, missing; context="simulate_ego_sample")` first (`supports_missing == true`, `missing_policies == (:error, :face)`); directed, two-mode (`Network` with `bipartite`, or a `BipartiteNetwork` method) and unknown/partial `ego_attrs` are refused with actionable ArgumentErrors; an ego's own loop is never an alter; `report=true` returns `(ed, ConversionReport(:Network, :EgoData))` recording `:edges` (when `n_egos < nv`), `:vertex_attrs` (each unrequested one), `:edge_attrs`, `:network_attrs`, `:loops` (loops flag) and `:missing_dyads` (under `:face`). Attribute columns are built once per attribute (`columns[attr] = [vals[v] for v in 1:n]`) and sliced per ego, so an isolate's empty `alter_attrs[attr]` has the same concrete eltype as its neighbours' (it used to be a `Vector{Any}`). The NetworkCore.jl invariant table column `Network→EgoData` (`conversion_invariants.md`, footnotes [^7]/[^10]) still records the pre-0.2 unguarded adapter; the cross-repo update is requested (see Conventions) and the testset "Missing dyads and the conversion contract" pins every cell.
7. **Diagnostics** — `gof(result; n_sim, rng, burnin, interval, n_chains, proposal)` (a method of `NetworkCore.gof`) runs `_gof_simulations`: the annealed pseudo-population model from `rng`, `sample_networks(...; rng, n_chains)` at `_pseudo_theta(result)` with the `_mcmc_controls` budget, and from each simulated network an ego sample **with the observed design** (`_design_sample`: one vertex per observed ego, uniform among the pseudo-population vertices that replicate it, carrying that ego's weight — so the simulated column is the same weighted estimator as the observed one; the pre-0.2 unweighted SRS had too narrow an envelope under unequal weights). p-values are `NetworkCore.mc_pvalue` via `GOFStatistic`. Statistics, in order: `"model statistics"` (every ego term per capita — R's `GOF="model"`; fitted targets, so a simulator/convergence check), `"degree distribution"` (R's bins from `_degree_gof_bins(K, m)`: `EgoDegree(d)` for `d in 0:maxdeg-1` plus the tail `_EgoDegreeAtLeast(maxdeg)`, `maxdeg = 2·max(K, 3)`; R's no-tail branch when `maxdeg ≥ m − 1`), `"edgewise shared partners"` (`_EgoESP(k)`, `k = 0:2(max(K,3)−1)` — R's `GOF="espartners"`; per-ego contribution `count(==(k), alter_degree(e))/2`; only when alter ties were collected) and `"ego summary statistics"` (mean degree and, when collected, mean alter ties). `ego_gof` is a thin wrapper reading the LAST statistic out as a NamedTuple. The suite pins two-call equality, global-RNG non-consumption, and thread-count independence in a fresh `--threads=` process.
8. **Precompile workload** — at the end of the module (`PrecompileTools`): edges-only and nodematch (string and integer attribute — the sampler specializes on the attribute type) fits, `show`, `gof`, under a `NullLogger` with a local rng.

### The census fixture

The census is chosen because it makes two of the three compared quantities **deterministic**, so neither can be excused as Monte-Carlo noise.

**1. Targets.** Under a census they reduce to the observed network's own statistics (edges = 203, nodematch.Grade = 163). ERGMEgo.jl reproduces them exactly.

**2. The design variance — a bug found by the fixture and FIXED.**

> **`_design_cov` was too small by exactly the factor (n−1)/n.**

Not approximately; exactly, in every entry. It summed `m² Σᵢ wᵢ²(hᵢ−h̄)(hᵢ−h̄)′` with `wᵢ = 1/n`, i.e. it divided the sum of squared deviations by `n`. The survey (SRS / Horvitz–Thompson) variance of a mean, which `ergm.ego` computes, divides by `n−1`. At n = 205 the standard errors came out **0.24% narrow**.

`_design_cov` now applies the Bessel correction (`Σ .*= n/(n-1)`) and matches `ergm.ego` outright; the testset asserts exact agreement (`design_std_errors = 1e-9`) and pins the correction against an independent `Statistics.cov` reference (`Σ ≈ m²·cov(H)/n`) and a hand-computed weighted three-ego case, so removing it cannot pass silently. This mattered more than 0.24% suggests: the fixture shows **the design component is 17× the estimation component**, so an ego standard error essentially *is* its design variance.

The fixture also freezes the design SEs of the *coefficients* with the **exact** information (`design_se_exact`, from the plain ERGM's `vcov` — MPLE = MLE for this dyad-independent model — sandwiching `Σ_design`; agrees to 1e-6), R's own MCMC estimate of the information (`r_DtDe`, 12 % off the exact `I⁻¹[1,1]`), and `ergm.ego`'s SE decomposition (`mle_se_design_component`, `mle_se_estimation_component`, `mle_std_errors`). The Julia fit's `vcov_design`/`stderror` are held to 0.06 per fit — R's 0.022 offset from the exact value plus 3× the Julia per-fit sd of 0.013.

(The other half of the question — strata, clusters, FPC, without-replacement inclusion probabilities — a census cannot expose, because ERGMEgo.jl cannot express a design that would; it is a documented limitation.)

**3. Parameterization.** The fixture's R fit used the default `popsize = 1`: a fixed offset `netsize.adj = −log(205) = −5.3230` plus a free per-capita `edges` coefficient (−0.6974). The census ego data carries `population_size = 205`, so the default Julia fit is `ergm.ego` with `popsize = 205` (offset 0, edges −6.03, compared with the frozen sum `mle_coefficients_population`), and `fit_ergm_ego(ed, …; popsize=1, ppopsize=205)` reproduces R's default output (`mle_coefficients`, `netsize_adjustment`) — both are asserted. It is independently anchored by a plain (non-egocentric) `ergm` MPLE of the same model on the same network (−6.034) — which a census fit *must* reduce to, and both packages do.

**4. The defaults did not converge at realistic size — now dyad-scaled, with a real convergence test.** The old defaults were fixed constants (`n_samples=400, burnin=2000, interval=20`) that did not grow with the pseudo-population, so the chain stopped mixing as `m` rose: the 205-actor census returned `edges ≈ −21.9` against a true `−6.02`, off by a factor of three, on a network the size of the standard teaching dataset. (It did set `converged == false`, which is the one thing that stood between a user and a published wrong number.)

The MCMC controls now follow ERGM.jl's **one dyad-scaled rule** (`_mcmc_controls` → `ERGM.Extension.mcmc_defaults`: burnin `20·n_dyads`, interval `max(100, n_dyads ÷ 10)`, up to 3000 draws), and `maxiter` defaults to 60. With ERGM.jl's tie/no-tie proposal the 3000 draws carry 1000–3000 effective draws (so the estimation SE component is 0.35–0.6 of `ergm.ego`'s; the census testset holds it two-sided, `r/4 < j < r`, and asserts the identity `vcov_estimation == I⁻¹/n_eff`). With the annealed start the census converges in one or two iterations (≈ 2.5 s per fit) on the exact MLE of the targets (−6.034, 2.831). All controls remain overridable; passing `nothing` selects the scaled default. The census egodata used by the tests is built from `load_dataset(:faux_mesa_high)` (checked against the fixture's frozen edge list), and the golden testset takes ≈ 25 s.

## Conventions

- All code resides in a single file (`src/ERGMEgo.jl`); there are no `include` statements.
- Types are parametric on vertex ID type `T` (e.g., `EgoNetwork{T}`, `EgoData{T}`).
- Each ERGM term is a struct subtyping `AbstractERGMTerm` with two required methods: `name(t)::String` and `compute(t, ed::EgoData)::Float64`.
- Weighted statistics use `ed.sampling_weights` paired with `ed.egos` via `zip`.
- Networks are assumed undirected (alter ties divided by 2 in `n_alter_ties`).
- Julia docstrings are used on all exported functions and types.
- Every random draw flows through the `rng` keyword (`_pseudo_population` seeding, `_san!`, `mh_sample`, `_design_sample`); never call bare `rand()`. The test suite pins that two fits from the same `rng` state are bit-identical regardless of the global RNG.
- Richer survey designs are a documented limitation (README "Not implemented", `show`, `approximations`), not a bug. Code, tests and docs carry no internal process references (no review ids): a comment explains the reason.
- Actionable errors are the rule: a routine that meets a mistake (missing attribute or `missing` value, unknown column, directed/two-mode/masked input, a pseudo-population below 5, an empty `EgoData` in `summary_stats`, a NaN/Inf/negative/all-zero sampling weight, a duplicated alter or an alter self-tie, an unknown `estimate_popsize` method) throws an `ArgumentError` naming the thing and the fix; it never returns a number computed around it.
- Public surface beyond the exports: `public ergm_term, ego_contribution` — the two hooks a custom `EgoTerm` extends (both documented with runnable examples — `names(ERGMEgo)` lists public names, and the docstring testset walks it). No underscore name is `public` (the "Shared contracts" testset asserts it). ERGM.jl's building blocks come from its extension API: `import ERGM.Extension: mcmc_defaults, mcmle_sampler, confidence_test, attainable_range` (the last extended for `EgoTerm`); the source scan asserts no `ERGM._x`/`NetworkCore._x` appears, no imported name starts with `_`, and each of the four is `===` ERGM's, together with `Base.ispublic(ERGM, :mcmc_convergence)`.
- README "Not implemented" and CHANGELOG "Known limitations" carry the same nine bold-lead items in the same order; a testset compares the leads. The CHANGELOG `[0.2.0]` section is condensed release notes (no review-round references) — add to it in that style.
- Aqua (`Aqua.test_all(ERGMEgo; ambiguities=false)` plus `Test.detect_ambiguities(ERGMEgo)`) runs in the suite; every `[extras]` entry has a `[compat]` bound (so `Graphs` IS in `[compat]`, while staying out of `[deps]`). `docs/Project.toml` has `[compat]` too.
- The "Workflows reconstruct the ecosystem layout from [sources]" testset runs the workflows' generated layout step in check-only mode (the site's `tools/sync_workflows.jl` owns that step) and asserts the thread cell and the benchmark gate are still in `CI.yml`. It runs the step only when at least one `[sources]` sibling (`ERGM.jl`, `NetworkCore.jl`, a directory with a `Project.toml`) is beside the package (`present_siblings`, pinned on a scratch directory); with none — a lone checkout or a registry install — it says so in an `@info` and records a `@test_skip`; a partial layout runs and fails. The fresh-process tests (bootstrap, gof thread independence) print the subprocess's stderr when it fails.
- Requires Julia >= 1.12.
